\section*{Data availability}
All analysis code (data retrieval, feature construction, model fitting, the oracle and MOS protocols, the leave-one-system-out harness and the figure scripts) is available at \url{https://github.com/DT-Service-Consulting/solcent}, tag \texttt{v1.4-paper}. The archive includes the derived outputs needed to reproduce every table and figure; the per-row test predictions used by the significance tests are regenerated by the model drivers with the \texttt{-{}-save-preds} option. Weather forecasts are retrieved from the Open-Meteo archive (CC BY 4.0); retrieval scripts are supplied instead of the fields, because upstream providers have their own terms. SARAH-3 is available from EUMETSAT CM SAF \citep{Pfeifroth2023}. PV generation data are published by system owners on PVOutput.org, whose terms do not allow redistribution. The archive therefore contains the system identifiers and the retrieval script, so that any user with PVOutput access can rebuild the dataset.
