\section*{Data availability}
Code and the derived results behind every table and figure are available at \url{https://github.com/DT-Service-Consulting/solcent}, tag \texttt{v1.4-paper}. Weather forecasts come from the Open-Meteo archive (CC BY 4.0) and SARAH-3 from EUMETSAT CM SAF \citep{Pfeifroth2023}; retrieval scripts are supplied instead of the fields. PV generation data are published by system owners on PVOutput.org, whose terms do not allow redistribution; the repository gives the system identifiers and a retrieval script to rebuild the dataset.
